# Publication security and responsible research

This repository describes **unofficial** REST and WebSocket research, not a tested or supported irrigation-controller client. Never treat inventoried control methods/events as approved, safe, or reversible operations.

Do not publish credentials, signed S3 URLs, account/user/device/mesh IDs, raw authenticated responses, private historical archives or personal watering data. Only synthetic `example.invalid` examples belong in this reference.

Do not follow unverified redirects, brute-force API routes, access other accounts or send watering/program/rain-delay/state-changing commands on the basis of this research. Report a potential secret leak privately to the repository owner, not in a public issue.

The project is not affiliated with Orbit Irrigation.
